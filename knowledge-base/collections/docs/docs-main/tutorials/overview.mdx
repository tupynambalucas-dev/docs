# Primeiros Passos no Academic Lab

Neste tutorial, você aprenderá a clonar o repositório, instalar as ferramentas necessárias,
verificar a integridade do código com Turborepo e construir a base de documentação em seu computador.

---

## Pré-requisitos

Antes de iniciar, certifique-se de possuir em seu sistema:

- **Node.js** na versão 20.0 ou superior.
- **pnpm** na versão 12.6.0 ou superior (`corepack enable pnpm` ou instalador oficial).
- **Git** configurado para controle de versão.

---

## Passo 1: Clonar o Repositório

Abra o terminal e obtenha o código fonte oficial:

```bash
git clone https://github.com/tupynambalucas/academic-lab.git
cd academic-lab
```

---

## Passo 2: Instalar as Dependências

O Academic Lab utiliza catálogos rigorosos do pnpm para garantir consistência de versões entre todos
os pacotes internos:

```bash
pnpm install
```

O pnpm conectará automaticamente os pacotes internos (`@academic-lab/*`) através de links
simbólicos no arquivo `pnpm-lock.yaml`.

---

## Passo 3: Checagem de Tipos e Validação

Para certificar-se de que não existem erros de TypeScript ou contratos rompidos em nenhum pacote,
execute a checagem com o Turborepo:

```bash
pnpm kb:typecheck
```

Você verá a execução em paralelo nos cinco pacotes do ecossistema, concluindo em segundos com
auxílio de cache inteligente:

```text
Tasks: 3 successful, 3 total
```

---

## Passo 4: Compilar o Portal de Documentação

Para gerar os arquivos estáticos de produção do Docusaurus e validar se todos os arquivos MDX
cumprem as regras do parser:

```bash
pnpm kb:build
```

O resultado será emitido na pasta `knowledge-base/apps/main/build`.

---

## Passo 5: Iniciar o Servidor de Desenvolvimento

Para trabalhar localmente com recarregamento em tempo real (_Fast Refresh_):

```bash
pnpm kb:dev
```

Acesse o endereço `http://localhost:3002` no navegador para explorar o portal com navegação fluida,
barra de pesquisa e tema estilizado.
