# Introdução às Referências Técnicas

O quadrante de **Referência Técnica** reúne as especificações formais, contratos de dados,
parâmetros de configuração e esquemas de código do **Academic Lab**.

---

## O Papel da Referência no Diátaxis

Documentos de referência são **orientados à informação**. Eles não tentam ensinar conceitos do
zero (papel dos tutoriais) nem instruir a realização de tarefas (papel dos guias):

- **Objetividade Absoluta**: Textos secos, informativos e com terminologia exata.
- **Estrutura Previsível**: Listagens tabulares, contratos de tipos e tabelas de parâmetros.
- **Confiabilidade**: Servem como fonte canônica de verdade para desenvolvedores e agentes de IA.
