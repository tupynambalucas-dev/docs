# Introdução aos Fundamentos & Arquitetura

O quadrante de **Explicação** no framework Diátaxis destina-se a responder ao "porquê". Ao contrário
dos tutoriais (como fazer pela primeira vez), guias (como resolver um problema específico) e
referências (como o sistema é estruturado), as explicações ampliam a compreensão holística do
estudante.

---

## O Propósito da Explicação no Aprendizado Científico

- **Contexto Histórico e Sistêmico**: Entender como as diferentes peças se encaixam.
- **Decisões de Design**: Expor os motivos pelos quais uma determinada solução foi escolhida em
  detrimento de alternativas comuns.
- **Formação Crítica**: Capacitar o estudante a refletir sobre a arquitetura e propor evoluções
  fundamentadas.
