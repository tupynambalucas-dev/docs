# Como Estruturar um Novo Tópico de Estudo

Este guia ensina como integrar uma nova matéria, disciplina ou tema de pesquisa acadêmica dentro da
estrutura de coleções do **Academic Lab**.

---

## Passo 1: Determinar o Quadrante Correto

Ao produzir novo material de estudo, classifique cada documento em um dos quatro quadrantes do
framework Diátaxis:

- `tutorials/`: Se for uma aula prática com passo a passo para quem nunca viu o tema.
- `guides/`: Se for um guia com soluções para problemas comuns ou técnicas de laboratório.
- `reference/`: Se for uma tabela de fórmulas, resumo de definições ou especificações técnicas.
- `explanation/`: Se for um ensaio teórico contextualizando conceitos e estado da arte.

---

## Passo 2: Criar o Diretório e o Arquivo `_category_.json`

Caso o novo tópico exija múltiplos documentos, crie uma pasta dentro do quadrante correspondente e
adicione o arquivo de metadados da barra lateral:

```json
// knowledge-base/collections/docs/docs-main/reference/meu-tema/_category_.json
{
  "label": "Nome do Tópico",
  "position": 3,
  "collapsible": true,
  "collapsed": false,
  "link": {
    "type": "generated-index",
    "description": "Notas e referências detalhadas sobre o tópico."
  }
}
```

---

## Passo 3: Redigir o Conteúdo em MDX

Crie os arquivos com a extensão obrigatória `.mdx`. Todo documento deve conter um cabeçalho
frontmatter padronizado:

```mdx
---
id: intro-meu-tema
title: Introdução ao Meu Tema
description: Resumo conciso sobre o escopo do documento.
sidebar_position: 1
---

# Introdução ao Meu Tema

Texto explicativo e didático em português (pt-BR)...

:::info[Nota Importante]
Utilize sempre admonitions nativas do Docusaurus para destaques essenciais.
:::
```

---

## Passo 4: Validar e Compilar

Após escrever os arquivos, valide a conformidade de compilação sem necessidade de subir servidores
manualmente:

```bash
pnpm kb:build
```

Se a compilação emitir `[SUCCESS] Generated static files in "build"`, seu novo tópico está pronto e
perfeitamente integrado à navegação do portal!
