# Introdução aos Guias Práticos

O quadrante de **Guias Práticos** (_How-To Guides_) reúne instruções orientadas a objetivos
específicos do dia a dia. Ao contrário dos tutoriais, que partem do zero para iniciantes, os guias
pressupõem que você já compreende o funcionamento básico do sistema e precisa de uma solução direta.

---

## Características de um Guia no Diátaxis

- **Foco em Resultados**: Cada guia responde a uma pergunta pontual (ex.: "Como adicionar um novo
  tópico de pesquisa?").
- **Sequência Direta**: Focado na ação, sem desvios teóricos desnecessários.
- **Flexibilidade**: Pode ser executado fora de ordem cronológica, conforme a necessidade de cada
  pesquisador.
