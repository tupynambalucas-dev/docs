# Diretrizes Éticas e Boas Práticas

A integração de agentes autônomos e modelos de linguagem no fluxo de pesquisa universitária exige
novas convenções éticas para assegurar a autenticidade e o mérito científico do pesquisador.

---

## 1. Transparência no Uso de Ferramentas de IA

No Academic Lab, recomendamos registrar de forma clara quando um agente ou ferramenta de IA foi
empregado para:

- Mapeamento bibliográfico e raspagem de dados via Firecrawl.
- Reformatação de sintaxe ou conversão para o framework Diátaxis via Docusaurus Expert.
- Elaboração de resumos conceituais preliminares.

O pesquisador deve atuar como auditor crítico, nunca aceitando respostas automáticas como dogmas
sem conferência direta na literatura de referência.

---

## 2. Boas Práticas na Criação de Conteúdo

1. **Evitar Generalidades**: Substitua afirmações vagas por dados concretos, fórmulas demonstradas
   ou referências bibliográficas pontuais.
2. **Manutenção de Exemplos Práticos**: Todo conceito teórico deve, sempre que possível, vir
   acompanhado de um exemplo funcional em código ou de um estudo de caso aplicado.
3. **Revisão Periódica**: Conhecimentos defasados devem ser atualizados ou explicitamente marcados
   com notas de contexto temporal.
