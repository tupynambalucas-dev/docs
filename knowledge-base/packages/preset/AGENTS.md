# Preset Package Context

This document serves as the sub-domain context router (Layer 3) for the packages/preset/ workspace.

## Purpose

This workspace (`@academic-lab/preset`) provides a custom Docusaurus preset that dynamically resolves documentation and blog collections, registers theme plugins, and orchestrates MDX remark transformers.

## Directory Layout

- [src/index.ts](./src/index.ts): Main preset factory function implementing dynamic collection path resolution.
- [src/options.ts](./src/options.ts): TypeScript type definitions for preset options.
- [src/themeConfig.ts](./src/themeConfig.ts): Standardized navigation, footer, and theme configuration helper.
- [src/sidebars/index.ts](./src/sidebars/index.ts): Autogenerated sidebar configuration.
- [src/plugins/content-docs/](./src/plugins/content-docs/): Content docs wrapper applying remark variables plugin.
- [src/plugins/content-blog/](./src/plugins/content-blog/): Content blog wrapper applying remark variables plugin.
- [src/plugins/ast-transformers/](./src/plugins/ast-transformers/): Remark plugins for frontmatter variable substitution.

## Scoped Guardrails

- MUST dynamically resolve docs collections from collections/docs/<collection-name>.
- MUST dynamically resolve blog collections from collections/blogs/<collection-name>.
- MUST delete opt.collection from options objects before delegating to Docusaurus core plugins.
- MUST keep all configurations JSON-safe to prevent circular reference serialization errors.
- MUST export sidebars and themeConfig for consumption by portal apps.
